# 🌸 Midnight Brew — Cozy Pink Aesthetic Barista Sim & Cafe

A relaxing, nostalgic 2D coffee barista simulation game styled in dreamy pink aesthetics, Lo-Fi rain ambience, dynamic customer stories, 3D foam latte art, and Mochi the living mascot cat!

![Midnight Brew Preview](/public/hero-cup.png)

---

## ✨ Features

- ☕ **5 Unique Game Modes:**
  - 📖 **Story Mode:** 12 unique customers with branching dialogue and personal stories.
  - ⚡ **Rush Hour:** 90-second speedrun with combo multipliers.
  - 🔍 **Mystery Drink:** Barista detective flavor puzzle mode.
  - 🧘 **Zen Lounge:** Ambient Lo-Fi radio with rain, thunder, snow, and sunrise sounds.
  - 🎨 **Latte Art Masterclass:** Interactive foam canvas drawing with 3-star scoring.

- 🐾 **Mochi the Living Cat Mascot:**
  - Transparent living animation that breathes, blinks behind pink sunglasses, stretches, grooms whiskers, takes cozy catnaps, laps up warm milk, and purrs when petted!

- 🥐 **Bakery & Warm Pastry Toaster:**
  - Croissants, Strawberry Shortcake, Matcha Mochi, Cinnamon Rolls, and Waffles with real-time oven baking and bell dings.

- 📸 **BrewGram & Social Feed:**
  - Customer DMs, reviews, and aesthetic Pinterest photography.

- 💾 **Auto-Save System:**
  - Keeps your coins, level, unlocked cup skins, and decor saved locally.

## 🚀 Quick Deploy to Vercel

### Option 1: Deploy with Vercel Web Dashboard (Recommended)

1. Push your repository to **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial cozy pink coffee cafe release"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset will automatically detect **Vite**.
5. Build Settings:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
6. Click **Deploy**! 🚀

---

### Option 2: Deploy with Vercel CLI

```bash
# Install Vercel CLI if you haven't already
npm i -g vercel

# Deploy directly from your terminal
vercel
```
